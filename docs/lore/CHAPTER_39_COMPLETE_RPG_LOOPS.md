## Chapter 39 Complete RPG Loops

The traveler must be able to spend supplies without losing an earned lesson, choose a recipe rather than accept an invisible default, and resume a remembered world without accidentally combining two lives. This source pass closes seven audited dependencies across the established nine realms. It changes access, transactions and presentation, preserving the existing cities, people, consequences and campaign outcomes. It does not select one protagonist or resolve an OPEN mystery.

### 39.1 Lessons and supplies

Local mastery now follows deeds. Rank one requires the personal accord, rank two also requires the opened route, and rank three requires the route cache. Training spends no local favor. Provisioning and danger kits still have their existing finite prices and benefits, so supplies remain consequential without permanently locking progression. A private compact and a public hearing retain their different social consequences; neither is a currency trap for learning.

An opened route cache can be inspected without spending a kit. The route and correct chamber must actually have been reached. A kit is used to suppress an unresolved chamber danger, where it offers a real benefit. Inspecting an already accessible clue does not discard one. Existing lower favor balances remain valid on restoration. Previous payments are not retroactively refunded and no earned proof is invented.

These rules apply equally in the Crossings, Saltwake, Cinderhold, Drevlach, Orravane, Vathless, Eillun, Tharniv and Auvren. The boss, rescue or investigation branch, dungeon wing and changed return remain the substantial adventure. Delivery remains one supporting activity.

### 39.2 A remembered session

The original save profile remains readable. Three additional profiles allow independent new games without deleting the existing record. New Game creates only an unused profile. Selecting an occupied profile loads it; selecting an empty or unreadable record explains the failure. An unsaved session cannot be silently discarded by a normal profile switch: the interface first tries to save and requires a repeated explicit action if that write fails. Changing the selected profile clears the pending confirmation.

All campaign systems now share the selected profile. Optional field-survey stages join that snapshot, so a scout's opened passage in one life does not appear in another. The original optional fieldwork file is read only for migration into the legacy profile, and remains intact. Invalid stage counts or values protect the record instead of being normalized into a fresh adventure.

Before replacing a compatible primary record, the previous committed record is written as its backup. A failed backup write refuses the new primary write. Recovering a selected compatible backup does not first overwrite it with the current session. An incompatible future schema remains preserved. These are portable transaction and source-routing contracts; platform storage failure, interrupted writes and actual engine reload remain acceptance work.

Resume stores the last earned safe settlement and the recorded health and stamina. It does not manufacture an exact mid-strike checkpoint. The world restores first, prepares local geometry and then places the traveler. Transient attack rhythm resets while persistent injuries, resources, quest decisions and consequences retain their saved authority. A periodic session snapshot supplements the existing world transactions; failed writes preserve the prior committed state.

### 39.3 Every action within reach

The journal now has Actions, Crafting and Session pages alongside Journal, Equipment, Map and Settings. Controller shoulders cycle all seven pages. Twenty-seven action buttons reach the actual existing ability, rite, confluence, faction, story, aid, supply, fieldwork and item handlers. Activating a gameplay action closes the paused menu before checking its real target.

This is access rather than permission to bypass the world. A rite still needs its earned discipline and situation. A rewrite still needs its physical object and valid state. A frontier crossing still uses its gateway. Aid still respects the person and their consent. A field technique still needs mastery, stamina and recovery time. No menu button settles Bes's unpaid wages or purchases Mera's willingness.

Prompts and physical signs resolve mapped controls. Controller prompts identify the mapped button or the relevant Actions entry when a dedicated button is absent. Keyboard remapping reaches interaction, combat, dodge and field technique guidance. Authored dialogue retains ordinary words, including the first-person pronoun, rather than treating every capital letter as an input.

### 39.4 Selectable regional recipes

The six existing workshop recipes retain their IDs, ingredients, profession requirements and workshop locations. The crafting page names the selected recipe, materials already owned, exact output and required workshop and skill. The crafting shortcut opens this selection instead of silently choosing the first affordable recipe. Materials and profession progress roll back together if the shared save fails.

Each completed optional realm wing teaches an additional field recipe. Crafting it requires the real earned workbench and its open hours. These recipes use registered materials and items; they do not add undocumented currencies or automatic wages.

Missing materials, an unlearned recipe or a full bag consume nothing. Successful work gives bounded practice in the recipe's existing profession. Optional recipe material scarcity cannot block the main adventure or the free mastery lessons.

Five common goods can be selected for buying or selling. The interface shows base prices and states that local trust can change buying prices. The transaction still requires the actual consenting merchant. A menu selection neither summons a vendor nor waives the inventory and funds checks.

### 39.5 A world with a simulation budget

World state and economic time continue to advance. Distant static block construction is deferred beyond the local geometry radius; the generated floors remain available, and an actual gateway or resumed settlement prepares its destination before moving the player. Nearby deferred construction drains in bounded batches. This prepares the primitive world for a smaller construction burst without claiming World Partition or measured performance gains.

Registered enemies, people and signs use refreshed weak caches rather than repeating whole-world scans for every nearby threat query. Enemy and character simulation intervals change with distance. Nearby combat keeps its full update rate; remote actors update less often. The world clock remains independent of that cadence, so walking away does not freeze service hours or the remembered economy.

Navigation, collision, streaming peaks, frame time and memory must be measured in Unreal. Source construction cannot establish a frame-rate target. All nine realms still contain prototype actors and data; this pass does not falsely claim that their entire residency has been removed.

### 39.6 Distinct warnings and everyday work

Each of the nine expedition bosses now carries a different visible prototype signature and an authored warning sentence. Those sentences accompany the actual existing counterplay warning. They reinforce identity while preserving the registered mechanics and injuries. Short attacks and stagger responses hold their presentation long enough to avoid immediate replacement by idle motion; death presentation remains sticky while the actor is defeated.

In repaired, open service halls, nearby residents can use a timed inspect, repair or gesture performance when resting. Urgent movement, refusal and existing routines remain authoritative. A work gesture does not generate items, complete a repair quest or award wages. It makes a service place less static without inventing an economic transaction.

The existing original sound library and prototype animation clips remain retained. Primitive signature props and reused clips are source presentation improvements, not bespoke final character rigs. Animation blending, skeletal import, audio mix, contact feedback and visual readability require engine acceptance.

### 39.7 The next audit

The repeatable gameplay dependency audit compiles and runs production-rule tests for all nine realm mastery paths after ordinary spending, atomic recipes and save recovery policy. It also checks that shared profile writes, resume geometry, actual action handlers, physical crafting targets, mapped signs and distance scheduling remain connected. Source CI runs this gate on subsequent changes.

A second pass already found and corrected the fixed optional-survey slot, a stale profile-switch confirmation and the automatic crafting shortcut. The audit records remaining engine checks explicitly. Its success means these tested portable rules and source contracts passed; it does not certify an Unreal executable or a finished commercial game.
