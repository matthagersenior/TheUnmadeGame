# THE UNMADE — confirmation of irreversible choices
**Unreal acceptance checklist. GitHub source tests do not count as a performed UE playtest.**

1. Start an uncommitted Refuge, Archive, Roadbound, Saltwake or Cinderhold first accord, Bellwold Afterlight or frontier return visit. A single F7 or F8 must show the named **actual local consequence** and never change the save/world.
2. Press the same ending a second time within six seconds while within the required representative's range: exactly one commit, visible world refresh, persistent narrative witnesses and finite earned rewards.
3. Press F7 then F8 within the window. F8 must only show a new preview, not commit F8. A second F8 within its own six-second period commits only if the validated evidence route allows that outcome.
4. Press F7 at one eligible NPC/arc, move to another eligible arc and press F7. The second must be a new preview; no confirmation token can migrate to a different story.
5. Wait more than six seconds; press the same key. No commit. A second press after that new preview should be valid.
6. Walk away, press invalid key/choice or lose the qualified witness/evidence. It must cancel the original pending token and require another conscious preview.
7. Test shared initiating NPCs (e.g. Hessa completing an older faction before Bellwold Afterlight): the higher-priority unresolved arc must be previewed and committed first, never a different chapter.
8. Force failed save writes. State changes must roll back, and retry needs another explicit confirmation. No doubled rewards or orphaned world geometry.
9. Test controller remappable equivalents, readable timed confirmation UI, narrator/screen reader text, and fair inability to accidentally select a permanent option without knowing its consequences.
