# The Unmade — Pre-Unreal Production Completeness Gate

**10 October 2026 | Hard acceptance ledger, not a declaration that the game is finished**

The creator's goal is to remove as many unknowns as possible before acquiring a Windows PC. This gate distinguishes **authored**, **native source-tested**, **Unreal Editor-required**, and **missing**. The bar is not 'many pages of lore': no world scene counts complete until its actors, outcomes, recovery, performance and audiovisual presentation have named owners and acceptance evidence.

Our nine-realm lived-universe atlas covers 27 physical clues, 18 ordinary resident scenes, nine optional five-step two-outcome side stories, nine inter-realm comparisons and 36 asset/audio work-order IDs. They are not implemented Unreal gameplay. This ledger is deliberately strict so the program never mistakes content counts for shipped depth.

## Release-blocking questions with explicit answers

**Is only installing Unreal left?** No. Unreal execution is a major missing *tool*, but actual visual assets, voice, animation, full dialogue trees, optional save states and many interactable scenes are still not pre-authored or implemented to final quality. These must not be silently reclassified as 'engine-only' tasks. Some can be prepared now as more detailed art/VO/action contracts; others require iterative engine feedback.

**Must the player visit all nine regions to finish the main plot?** No. The canonical Unanswered Road remains its existing tiered alternatives. Optional detours enrich understanding and relationships without becoming fake progress gates.

**Must the player use local AI, the internet or paid services?** No. Native decision and memory systems remain authoritative. Optional Ollama dialogue is presentation-only, disabled by default, and unverified in Unreal.

**Are complex choices safe?** Every consequential choice needs a concrete preview, explicit commitment, mutually exclusive durable result, failed-write rollback and reachable alternate safe route. Public world consequences may be observed by local residents without turning remote unknown facts into firsthand reports.

**What counts as a person who remembers?** Stable identity, role, relationship, witnessed/rumored provenance, daily activities, a personal belief with a human reason, two different return responses, individually assigned performance, visible impact from a witnessed choice and saved continuity. A generic line spoken by 82 NPCs does not meet the final bar.

**What counts as a discoverable mystery?** A physical site, an interaction that doesn't auto-complete, a question with multiple plausible explanations, at least two independent evidence sources, false lead safely falsifiable, accessible hint ladder, a revelation that affects future interpretation and lasting optional journal reference.

**What counts as an authored environment?** Reachable 3D geography, player collision, believable material affordances, navigation for inhabitants/enemies, visibility tests for hazards, non-color-only tells, weather/sound/day cycle, asset ownership, streaming budget, physical evidence stage and altered navigation after choices.

**What counts as an 'epic' final boss?** A justified dramatic truth from earlier quests, understandable attack windows, at least two materially different playable phases, the earned false victory, adaptive but deterministic testimony signature, no stolen user input controls, two affirmatively chosen persistent world futures, changed regions and a voluntary second encounter.

## Next pre-PC content contract

1. Every one of 82 residents needs a multi-session narrative card: stable ID, home/work/sleep locations, personal fear and desire, conflicting loyalty, known/unknown events, relationship limits, five unique dialogue moves and at least one consequence-aware return. Mark **missing** until individually reviewed.
2. Each of nine regions needs a topological traversal plan with landmarks, local route length estimates, safe bypass, geography-dependent hazard and world-state variants. Plans are *provisional* until verified on a real UE host.
3. Each full dialogue branch requires exact player response, actor gesture, interruption point, subtitle/voice variant, trigger, ineligible reason, no-dead-end recovery and effect on genuine canonical save state.
4. Every enemy and guardian needs animation beats, anticipation duration, hit geometry, accessible telegraph, non-cheating AI decision rule, recovery window, movement/obstruction interaction and tuning fixture.
5. Every important scene must have an art/rig/audio/Sequencer asset ticket and a source dependency that prevents lore drift. 'Describe a cutscene' is not equivalent to an editable Unreal Level Sequence.
6. The narrative ending must be tested against alternative and partial realm routes, saved older versions, nonviolent guardian outcomes, access setting changes and failure at each atomic save boundary.

## Verify

Pre-PC: run python Scripts/validate_lived_universe.py --check, python Scripts/build_world_content.py --check, python Scripts/build_cinematic_handoff.py --check, python Scripts/build_story_scene_handoff.py --check, python -m unittest discover -s Scripts/tests -v, and the existing native C++ GitHub checks.

First PC: run Scripts/first_pc_build_and_test.ps1, then real PIE and packaged-game scenario matrices. Keep compiler logs, level screenshots, traversal and collision clips, source-to-actor tag map, narrative branch screenshots, measured frame budgets and durable before/after saves. Static green CI is **not** engine-playable acceptance.

**Open creative requirement:** Immersion and challenge need creator playtests and iteration. No finite preproduction document can eliminate all game-feel decisions without using the engine. The objective is exhaustive preparation of decisions that can be made honestly before those playtests.
